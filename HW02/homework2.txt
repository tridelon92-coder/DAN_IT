a) Kernel — ядро
Kernel (ядро) — це головна частина Linux, яка керує ресурсами комп'ютера і взаємодіє безпосередньо із залізом.
Наприклад, у системі одночасно працюють браузер, Terminal і редактор коду. Усі вони хочуть використовувати процесор і оперативну пам'ять. Саме Kernel вирішує, кому, коли і скільки ресурсів надати.
Kernel відповідає за:
- процесор (CPU);
- оперативну пам'ять (RAM);
- диски та файли;
- запущені процеси;
- мережу;
- USB-пристрої;
- клавіатуру, мишу та інше обладнання;
- драйвери пристроїв.

Тобто Kernel — це головний керівник між програмами та обладнанням комп'ютера.

b) Libraries — бібліотеки
Libraries (бібліотеки) — це готові набори функцій, які можуть використовувати різні програми.
Замість того щоб кожному розробнику заново писати код для стандартних операцій, він може використати вже готову бібліотеку.

Наприклад, програмі потрібно:
- відкрити файл;
- записати інформацію у файл;
- працювати з мережею;
- показати текст;
- виконати математичну операцію.
Для багатьох таких речей уже існують бібліотеки.
Тобто Libraries — це готові інструменти для програмістів і програм.

c) System Utilities — системні утиліти
System utilities — це програми та команди, за допомогою яких користувач або адміністратор керує Linux.

Наприклад:
cd - переміщення між директоріями
cp - копіююваня файлів.
rm - виділення файлів або директорій
mv - переміщення файлів або перейменування
ls - показує файли та директорії

Тобто System Utilities — це набір інструментів для роботи з операційною системою.
